# Plett Lagoon Estate website

Static website built with Astro, Tailwind CSS and TypeScript, hosted on Cloudflare.

- Local preview: `npm install`, then `npm run dev`
- Build: `npm run build`
- How to update photos and documents: see [docs/UPDATING.md](docs/UPDATING.md)
- Conventions for AI-assisted work: see [CLAUDE.md](CLAUDE.md)
